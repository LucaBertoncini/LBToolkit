In particolare fai attenzione a:

STRUTTURA XML:
- Gli elementi <State> devono essere FIGLI DIRETTI di <StateMachine> (vietato usare tag
  contenitori come <States>).
- Gli elementi <SetOutput> devono essere FIGLI DIRETTI di <Preset> (vietato usare tag
  contenitori come <Actions> nei preset).

ESPRESSIONI:
- Le Expression supportano solo logica booleana e di confronto (EQ, NE, GT, LT, GE, LE,
  AND, OR, NOT) e la funzione TIMEOUT().
- È SEVERAMENTE VIETATO usare operatori matematici (+, -, *, /) o funzioni aritmetiche
  (Int(), Round(), ecc.) nelle Expression: l'engine supporta solo bcBoolean.
- TIMEOUT(NomeTimer) è un operando booleano autonomo: non scrivere mai TIMEOUT(T) EQ 1.

VARIABILI CONDIVISE:
- Le shared variables NON si dichiarano mai in <Inputs> o <Outputs> delle singole VM.
  Si usano direttamente per nome nelle Expression e nei SetOutput.
- Solo SharedVariables.xml le dichiara.

BOOT E SINCRONIZZAZIONE:
- Le VM slave devono attendere SystemBooted EQ 1 prima di uscire dallo stato iniziale.
- SystemBooted viene impostato a 1 dalla VM supervisore solo dopo la stabilizzazione
  di tutti i moduli.

INTERPOLAZIONE LOG:
- Nei messaggi <Log> usare SEMPRE %NomeVar% (singolo % prima e dopo il nome) per
  l'interpolazione dei valori correnti delle variabili.

TEMPLATE (.xplct / .xplci):
- I placeholder nei template hanno la forma $NomeParametro (prefisso $).
- La sostituzione avviene sulla stringa XML grezza prima del parsing DOM.
- I parametri senza Default sono obbligatori; quelli con Default sono opzionali.
- Il Code di ogni istanza deve essere univoco tra tutte le VM caricate.
- Evitare placeholder nei nomi degli stati: i log mostrerebbero nomi diversi per
  istanze diverse, rendendo il debug difficile.

BEST PRACTICE:
- Fermare i timer in OnExit (StopTimer per ogni StartTimer in OnEnter).
- Mettere le transizioni di sicurezza/manutenzione SEMPRE per prime.
- Inizializzare tutte le uscite nello stato iniziale/Idle.
- Azzerare la shared variable di comando nell'OnExit dello stato consumatore.
- Non assumere mai lo stato fisico degli attuatori al boot.
